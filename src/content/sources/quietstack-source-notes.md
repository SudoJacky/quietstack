# Quietstack Source Notes

## Repository-first publishing

Quietstack keeps long-form posts, short notes, pages, and source material in repository-backed Markdown files.

The publishing flow is designed so content can be updated independently from the visual theme.

## Static output

Production builds generate static HTML, feeds, search data, and a Pagefind index.
